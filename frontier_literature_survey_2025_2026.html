03多模态医学 Agent 与基础模型

这是与你项目最贴近的一支。重点看 Camyla——它几乎就是你的「论文版自己」。

★ Camyla: Scaling Autonomous Research in Medical Image Segmentation 中科大 / 上海创新院 / 上交 / 上海 AI Lab 已核实

论文：arXiv:2604.10696（2026-04-12，cs.AI）；代码 github.com/yifangao112/camyla；主页 yifangao112.github.io/camyla-page

定位：面向医学图像分割的全自主研究系统——把原始数据集自动转化为「有文献支撑的研究提案 → 可执行实验 → 完整稿件」，全程零人工干预。

它点名的三个长时挑战（与你 AUTONOMY_POLICY.md 的问题一一对应）

  • 搜索漂移（search effort drifts toward unpromising directions）
  • 知识退化（knowledge from earlier trials degrades as context accumulates）
  • 增量修补陷阱（recovery collapses into repetitive incremental fixes）

三个对应机制（方法核心）

  • QWBE（Quality-Weighted Branch Exploration）：把多提案搜索建模为带风险厌恶先验的 bandit 问题，动态分配算力、提案停滞时新建提案。
  • LRM（Layered Reflective Memory）：把实验知识分为 trial / cycle / global 三层逐级压缩，让编码 Agent 只拿到「决策相关」的信息。
  • DDF（Divergent Diagnostic Feedback）：用五建议诊断组合（架构/超参/代码修复/提案-实现缺口）替代单点纠错，跳出局部最优。

成果（可直接引用的硬数字）

  • 基准 CamylaBench = 31 个数据集，全部取自 2025 年发表（26 个为盲测）以规避数据污染。
  • 两轮独立运行、28 天、8 卡集群、零干预：生成 >2,700 个新模型实现 与 40 篇完整稿件。
  • 在相同训练预算下，超过「从 14 个成熟架构（含 nnU-Net）中挑出的最强单数据集基线」，两轮分别 22/31 与 18/31，并集 24/31。
  • 资深人类评审把生成稿件打在当代医学影像期刊的 T1/T2 分界线（T1 = TMI / MedIA）。
  • 相对自动化基线：在聚合 Dice 上超过 AutoML 与 NAS 系统；在任务完成率与「超越基线频率」上超过 6 个开放式研究 Agent（其中最强通用 Agent 仅完成 69% 任务，且 54% 出现提案漂移）。
  • 发布 CamylaTrace-232k：>232,000 条 Agent 事件、2,865 个编码会话、1,343 个模型实现。

它的评测协议（强烈建议你直接对齐）

主指标 = 前景类平均 Dice；次指标 = HD95。「超越基线」的两级判据：Dice 提升 > 0.5 个百分点；或 Dice 差距在 0.5pp 以内且 HD95 严格更低。理由：既防止用微小波动冒充成功，又在体积重叠接近饱和时承认边界质量改进。

它的呈现形式（论文骨架）

主结果图（逐数据集 Dice 提升 delta，区分验证/盲测）· 与 6 个开放式 Agent 的任务完成/漂移对比 · 稿件质量分层评审 · 组件消融 · 探索轨迹可视化 · 跨运行稳定性与方差 · 预算敏感度（累计胜率、首次成功位置）· 失败案例研究 · 统计显著性（binomial test + per-sample Wilcoxon）· 计算成本 · 轨迹数据集。

这是你的头号竞争对手，也是头号模板 Camyla 与你的项目在「任务（医学分割）、对照（nnU-Net）、协议（零干预）、产出（模型+稿件）」上高度重叠。你要么找到差异化定位（例如：更聚焦「可信/可审计的确定性判定」、或聚焦特定模态/竞赛排行榜名次、或强调 judge.py 的可复现治理），要么把 Camyla 当作直接 baseline 并说明你与它的差异。审稿人一定会问「你和 Camyla 有什么不同」。

4.2 度量长时能力：METR 时间视界

METR Task-Completion Time Horizon 已核实

定义：50%-time horizon = 以人类专家完成时间计，Agent 能达到 50% 成功率的任务时长。基于 100+ 个多样软件任务。

成果：o3 的 50% 时间视界约 110 分钟；前沿模型时间视界自 2019 年起约每 7 个月翻倍（2024 后可能加速）；官方明确标注 >16 小时的测量在当前任务集上不可靠。

呈现：对数/线性双坐标的 50% 与 80% 时间视界曲线，按模型发布时间排列。metr.org/time-horizons · arXiv:2503.14499

Horizon Leaderboard（arXiv:2604.11978）另提供模型榜：Claude-4-Sonnet 平均通过率 34%、GPT-5-mini 32%；break level 随领域变化（Web s=1 / OS s≈3 / Database s≈5）。需复核

4.3 过程验证与「何时该停」

VPRM · Verifiable Process Reward Models arXiv:2601.17223 需复核

方法：每一步 reasoning 由确定性 verifier 评估，奖励来自显式任务准则而非只看最终答案。

SEVA · Self-Evolving Verification Agent arXiv:2606.29713 需复核

方法：把验证质量分解为 5 个独立组件，70/30 权重偏向过程信号。

成果：alignment 0.917 → 0.997；format 72% → 100%；F1 64.9 → 69.0。

语义早停 arXiv:2606.27009 需复核

方法：当连续草稿 embedding 语义不再变化、且答案质量不再提升时停止——替代机械的 token 计数 kill-switch。

方法：episode 前 R 轮用 probe 检测失败信号，超阈值即 abort；用 Clopper–Pearson 下界校准每轮 recall 预算。

4.4 可复现性 / 确定性评测
